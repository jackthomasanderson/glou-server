# Cellar Management

## TL;DR
Organize bottles into named physical locations (Cellars).

## Action
1. Go to **My Cellars** page.
2. Click **New Cellar**.
3. Enter Name (e.g., "Living Room Fridge").
4. Select Type:
   - **Wine**: Default constraints.
   - **Spirits**: Optimized for open bottles.
   - **Cigars**: Humidity tracking focus.

> [!TIP]
> You cannot add a bottle without creating a cellar first.
