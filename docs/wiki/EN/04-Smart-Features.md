# Smart Features

## TL;DR
Automated tracking for drinking windows and consumption.

## Apogee Alerts
- **Status Indicators**:
  - 🟢 **Incubating**: Keep it.
  - 🟡 **Drinking Window**: Ready to drink.
  - 🔴 **Peak Maturity**: Drink now (priority).
  - 🟣 **Declining**: Past peak.

## Level Tracking
- Track open bottles (Spirits/Wine) using the visual slider.
- Precision: 10% increments.

## Smart Suggestions
- Click **"What to drink?"**.
- Algorithm selects based on:
  1. Peak Maturity (limit waste).
  2. Open bottles (finish first).
