# Search Your Cellar (Global Search Bar)

## TL;DR
The navbar search bar queries your full inventory in real time. Type any part of a name, producer, or vintage — results appear instantly.

## Prerequisites
- Logged into your account.
- At least one bottle in your inventory.

## Action

1. Click the search icon **🔍** in the top navigation bar.
2. Type your search term (minimum 1 character).
3. Results appear in a dropdown panel below the bar.
4. Click a result to open that bottle's detail view.

> [!TIP]
> Search is case-insensitive and accent-tolerant. "chateau" matches "Château".

## Fields covered by the search

| Field | Example |
| :--- | :--- |
| Product name | `Petrus`, `Moët` |
| Producer | `Château Margaux`, `Hennessy` |
| Vintage | `2015`, `2019` |
| Category | `wine`, `spirit` |

## The Firewall (Troubleshooting)

| Error / Behavior | Fix |
| :--- | :--- |
| **No results for a known bottle** | Check spelling. Search runs against stored data: if the name was abbreviated at entry, search for the abbreviation. |
| **The panel doesn't open** | Click directly on the text input area, not the icon alone. |
| **Too many results** | Narrow it down by combining terms: type `Bordeaux 2018`. |
