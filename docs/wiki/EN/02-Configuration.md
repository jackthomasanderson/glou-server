# Environment setup

**TL;DR**: Everything is configured through the `.env` file next to `docker-compose.yml`. Three values are mandatory and have no safe default: `DB_PASSWORD`, `JWT_SECRET` and `CONFIG_ENCRYPTION_KEY`.

**Prerequisites**:
- The `.env` file created from `.env.example` (`cp .env.example .env`).

**Action**:
1. Open the `.env` file in the project root.
2. Set the three mandatory secrets (generation commands in [Installation](./01-Installation.md)): `DB_PASSWORD`, `JWT_SECRET` (`openssl rand -base64 48`) and `CONFIG_ENCRYPTION_KEY` (`openssl rand -hex 32`, exactly 64 hexadecimal characters).
3. If you open Glou by anything other than `http://localhost:3000` (a NAS IP, a domain name), set `APP_URL` to that exact address and `CORS_ORIGIN` to the same value.
4. Apply the changes: `docker compose up -d` (this recreates the containers whose variables changed).

## Variables

| Variable | Default | Purpose |
| :--- | :--- | :--- |
| `DB_PASSWORD` | none, **required** | PostgreSQL password. `docker compose up` refuses to start without it. |
| `DB_USER` / `DB_NAME` | `glou` / `glou_db` | PostgreSQL role and database. Only read when the `db` volume is first created. |
| `JWT_SECRET` | none, **required** | Signs session tokens. The API exits at startup if it is empty or still the `.env.example` placeholder. |
| `CONFIG_ENCRYPTION_KEY` | none, **required** | 64 hex characters. Encrypts the SMTP password, Gotify token and integration keys stored in the database. Same startup check as `JWT_SECRET`. |
| `NODE_ENV` | `production` | In `development`, the secret checks only log a warning. |
| `APP_URL` | `http://localhost:3000` | Public address of the web app. `https://` marks session cookies `Secure` and enables HSTS; `http://` does neither. Also the fallback for links generated by the app (see [Network & Public URL](./16-Network-Public-URL-Configuration.md)). |
| `CORS_ORIGIN` | `http://localhost:3000` | Origin(s) the API accepts requests from. Usually the same value as `APP_URL`. |
| `CSRF_TRUSTED_ORIGINS` | empty | Extra browser addresses allowed to send requests, comma-separated (for example a second hostname). |
| `COOKIE_SECURE` | empty | `true`/`false` forces the `Secure` flag on cookies, for example when TLS is terminated by a proxy while `APP_URL` says `http://`. |
| `FORCE_HSTS` | empty | `true`/`false` forces the `Strict-Transport-Security` header regardless of `APP_URL`. |
| `NEXT_PUBLIC_API_URL` | `http://api:3001` | Where the web container reaches the API inside the compose network. Leave it alone in Docker. |
| `OLLAMA_URL` | `http://ollama:11434` | Vision model used by the [label scan](./26-Label-Scan.md) (only with `--profile scan`). |
| `OLLAMA_MODEL` | `moondream` | Model name used for the scan. |
| `OLLAMA_TIMEOUT_MS` | `600000` | Maximum time to wait for the model per scan, in milliseconds. |
| `API_RATE_LIMIT_MAX` | `1000` | Advanced. Requests allowed per IP address every 15 minutes on the API and uploaded images; a positive whole number, anything else is ignored with a warning in the API logs. Raise it only if many devices share one address and get `Too many requests`. The sign-in and password-reset limits do not change. |

> [!NOTE]
> `PUID`/`PGID` are not supported: the API container always runs as user `1001:1001`.

Settings that live in the app rather than in `.env` (SMTP, notifications, retention, backups, public URL, registration) are under **Administration → System Configuration**, see [Installation](./01-Installation.md).

**Troubleshooting**:

| Error | Resolution |
| :--- | :--- |
| `DB_PASSWORD is not set` | Set `DB_PASSWORD` in `.env`. There is no fallback password. |
| API logs `🛑 [startup] FATAL` and exits | `JWT_SECRET` or `CONFIG_ENCRYPTION_KEY` is missing, empty, still the placeholder, or (`CONFIG_ENCRYPTION_KEY`) not 64 hex characters. |
| `password authentication failed for user` | `DB_USER`, `DB_PASSWORD` and `DB_NAME` must match what was used when the `db` volume was first created. Changing `DB_PASSWORD` later requires changing it inside Postgres too, see [Rotate the Secrets](./29-Secret-Rotation.md#rotate-db_password); otherwise wipe the `db_data` volume, which deletes all data. |
| Signed out immediately, or sign-in fails, when opening Glou by IP | Set `APP_URL` to the exact address you type in the browser, then recreate the `api` and `web` containers. |
