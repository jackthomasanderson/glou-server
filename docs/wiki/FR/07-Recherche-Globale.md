# Rechercher dans votre Cave (Barre de Recherche Globale)

## TL;DR
La barre de recherche dans la navbar interroge votre inventaire complet en temps réel. Tapez n'importe quelle partie du nom, du producteur ou du millésime — les résultats s'affichent instantanément.

## Prérequis
- Être connecté à son compte.
- Avoir au moins une bouteille dans l'inventaire.

## Action

1. Cliquez sur l'icône loupe **🔍** dans la barre de navigation en haut de page.
2. Saisissez votre terme de recherche (minimum 1 caractère).
3. Les résultats apparaissent dans un panneau déroulant sous la barre.
4. Cliquez sur un résultat pour ouvrir la fiche de la bouteille.

> [!TIP]
> La recherche est insensible à la casse et à l'accentuation. "chateau" retrouve "Château".

## Champs couverts par la recherche

| Champ | Exemple |
| :--- | :--- |
| Nom du produit | `Petrus`, `Moët` |
| Producteur | `Château Margaux`, `Hennessy` |
| Millésime | `2015`, `2019` |
| Catégorie | `vin`, `spiritueux` |

## Le "Pare-feu" (Troubleshooting)

| Erreur / Comportement | Résolution |
| :--- | :--- |
| **Aucun résultat malgré une bouteille connue** | Vérifiez l'orthographe. La recherche porte sur les données saisies : si le nom a été abrégé à l'ajout, recherchez l'abréviation. |
| **Le panneau ne s'ouvre pas** | Cliquez directement sur le champ texte de la loupe, pas sur l'icône seule. |
| **Résultats trop nombreux** | Affinez avec le millésime ou la catégorie : tapez `Bordeaux 2018`. |
