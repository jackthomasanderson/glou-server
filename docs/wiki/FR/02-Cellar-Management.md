# Gestion des Caves

## TL;DR
Organiser les bouteilles dans des lieux physiques nommés (Caves).

## Action
1. Aller sur la page **Mes Caves**.
2. Cliquer sur **Nouvelle Cave**.
3. Saisir le Nom (ex: "Frigo Salon").
4. Choisir le Type :
   - **Vin** : Contraintes par défaut.
   - **Spiritueux** : Optimisé pour bouteilles ouvertes.
   - **Cigares** : Focus suivi humidité.

> [!TIP]
> Impossible d'ajouter une bouteille sans créer une cave d'abord.
