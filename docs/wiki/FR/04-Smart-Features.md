# Fonctions Intelligentes

## TL;DR
Suivi automatisé des fenêtres de dégustation et consommation.

## Alertes d'Apogée
- **Indicateurs de Statut** :
  - 🟢 **En Garde** (Incubating) : Garder.
  - 🟡 **À Boire** (Drinking Window) : Prêt.
  - 🔴 **Apogée** (Peak Maturity) : Boire maintenant (priorité).
  - 🟣 **Déclin** (Declining) : Passé l'apogée.

## Suivi de Niveau
- Suivre les bouteilles ouvertes (Spiritueux/Vin) via le slider visuel.
- Précision : incréments de 10%.

## Suggestions Intelligentes
- Cliquer sur **"Que boire ?"**.
- L'algorithme sélectionne selon :
  1. Maturité (limiter le gaspillage).
  2. Bouteilles ouvertes (finir d'abord).
