# Préférences Utilisateur

## TL;DR
Personnalisez votre expérience et sécurité.

## Paramètres de Profil
- **Langue** : Basculer entre Anglais / Français.
- **Options de Vue** :
  - **Grille** : Cartes visuelles (idéal pour naviguer).
  - **Liste** : Lignes compactes (idéal pour inventaire).

## Sécurité (2FA)
1. Aller dans Profil > Sécurité.
2. Activer **Authentification à Deux Facteurs**.
3. Scanner le QR code avec une App Authenticator.
4. Sauvegarder les **Clés de Secours**.

> [!CAUTION]
> Si vous perdez votre appareil et vos clés de secours, vous perdez l'accès au compte.
