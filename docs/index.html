Quick start

1

Configure

Copy the env file and set three mandatory values — none of them has a safe default.

cp .env.example .env
⚠️ DB_PASSWORD, JWT_SECRET (openssl rand -base64 48), and CONFIG_ENCRYPTION_KEY (openssl rand -hex 32). Running with placeholder values makes all user sessions trivially forgeable.
2

Launch

Docker pulls the pre-built images and starts the stack. No compilation required.

docker compose up -d
ℹ️ The AI label scan is optional and off by default (~9 GB disk, ~3 GB RAM). Enable it with docker compose --profile scan up -d.
3

Create your account

Open localhost:3000 and click Register. The first account created is automatically granted admin privileges.

💡 To update later: docker compose pull && docker compose up -d
Where it's headed

Roadmap

Recently added

  • Expert / Collector Mode — sommelier-grade tasting grid, appellation & cask fields, humidor panel.
  • Express label scanning — self-hosted, CPU-only vision model pre-fills name, producer, category, vintage.
  • Guided food pairing — ranked shortlist from your own cellar with one-click "drink it now".
  • Smart consumption plan — a personal drink-now / drink-soon list.
  • Wishlist & budget tracking with deal alerts and spending envelopes.
  • Trusted offline mode with auto-sync and conflict resolution.
  • World map, heatmap & filters.
  • Scheduled backups & data portability.

Next up
