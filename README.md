# 🍷 Glou — Your Friendly Cellar Companion

**Glou** is the simplest way to keep track of your favorite wines, spirits, and cigars without the headache! Whether you're a casual sipper or a serious collector, Glou makes managing your stash as easy as pouring a glass. No more wondering "where did I put that bottle?" or "is this still good to drink?" — Glou has your back, keeping your collection organized and ready for your next toast! 🥂

---

## ✨ Main Features

1.  **Smart Stash Management** — Easily add and organize your bottles and cigars with fields that actually make sense.
2.  **Safety First** — Keep your collection private with secure login and two-factor authentication (2FA).
3.  **Oops-Proof Trash** — Accidentally deleted a bottle? No worries! You have 7 days to bring it back from the trash.
4.  **Personal Style** — Customize your profile, choose your favorite theme (Dark Luxury included!), and set up notifications your way.
5.  **Fluent in Two Languages** — Glou speaks both English and French perfectly.

---

## 🚀 Quick Start

The easiest way to get Glou up and running is using **Docker Compose**.

1.  **Get the code**:
    ```bash
    git clone https://github.com/yourname/glou-server.git
    cd glou-server
    ```

2.  **Set up your settings**:
    Copy the example settings file and add your own password:
    ```bash
    cp .env.example .env
    ```

3.  **Launch!**:
    ```bash
    docker-compose up -d
    ```

Glou will be waiting for you at `http://localhost:3000`! 🎈
