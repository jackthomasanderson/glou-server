# 🍷 Glou — Votre compagnon de cave convivial

**Glou** est le moyen le plus simple de suivre vos vins, spiritueux et cigares préférés sans vous prendre la tête ! Que vous soyez un dégustateur occasionnel ou un collectionneur passionné, Glou rend la gestion de votre stock aussi facile que de se servir un verre. Plus besoin de se demander "où ai-je mis cette bouteille ?" ou "est-ce encore bon à boire ?" — Glou veille sur votre collection et la tient prête pour votre prochain toast ! 🥂

---

## ✨ Caractéristiques principales

1.  **Gestion intelligente du stock** — Ajoutez et organisez facilement vos bouteilles et cigares avec des champs qui ont vraiment du sens.
2.  **La sécurité avant tout** — Gardez votre collection privée grâce à une connexion sécurisée et une authentification à deux facteurs (2FA).
3.  **Corbeille anti-erreur** — Vous avez supprimé une bouteille par erreur ? Pas de panique ! Vous avez 7 jours pour la récupérer dans la corbeille.
4.  **Style personnel** — Personnalisez votre profil, choisissez votre thème préféré (Dark Luxury inclus !) et configurez vos notifications comme vous le souhaitez.
5.  **Bilingue** — Glou parle parfaitement l'anglais et le français.

---

## 🚀 Démarrage rapide

Le moyen le plus simple de lancer Glou est d'utiliser **Docker Compose**.

1.  **Récupérez le code** :
    ```bash
    git clone https://github.com/yourname/glou-server.git
    cd glou-server
    ```

2.  **Configurez vos paramètres** :
    Copiez le fichier d'exemple et ajoutez votre propre mot de passe :
    ```bash
    cp .env.example .env
    ```

3.  **Lancez !** :
    ```bash
    docker-compose up -d
    ```

Glou vous attendra sur `http://localhost:3000` ! 🎈
